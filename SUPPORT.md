# Tafind support

Publisher: **Talgat Ashim**.

For questions, bugs or feedback, [open a GitHub issue](https://github.com/ashimov-commits/tafind/issues/new). A GitHub account is required to post an issue.

GitHub issues are public. Do not include passwords, API keys, account tokens, private messages, personal data or confidential research. Share a minimal public example, the host you used, expected behavior and what actually happened. Remove private information from screenshots and attachments.

For sensitive issues, first open a short issue without confidential details and request an appropriate private contact method. Do not post the sensitive material publicly. No private support channel or response-time guarantee is currently offered.

Questions about your ChatGPT/Codex account, billing or platform access should go to the host's support provider.
